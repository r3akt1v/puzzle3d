# Puzzle3D — 3D-головоломка «Пазл»

3D-пазл на Unity: изображение режется на фрагменты правильной формы (с «клип»-вырезами), которые нужно собрать перетаскиванием на общий стол. Процедурная генерация уровней, таймер, система подсказок, звуковое сопровождение.

## Особенности

- **Процедурная генерация пазла** — изображение делится на сетку, границы кусков получают случайные «карманы» (выпуклости/вогнутости) через алгоритм **ear clipping**
- **5 уровней сложности** — от 3×3 до 8×6 фрагментов
- **Drag & Drop** — перетаскивание кусков с привязкой к поверхности стола, поворот камеры
- **Система подсказок** — подсветка/автосборка сложных мест
- **Таймер и условия победы** — сборка всех фрагментов за минимальное время
- **Процедурный звук и окружение** — генерация текстур/геометрии сцены кодом
- **Сохранение прогресса** между сессиями

## Стек

- **Unity 6000.6 (Unity 6)**, C#
- Процедурная генерация мешей и текстур (без внешних ассетов)
- Unity UI (uGUI)

## Запуск

1. Открыть проект в Unity Hub (версия **6000.6.7f1**)
2. Открыть сцену `Assets/Scenes/Main.unity`
3. Нажать Play

## Структура

```
Assets/Scripts/
  GameManager.cs       — состояние игры, уровни, таймер, победа
  PuzzleGenerator.cs   — генерация сетки пазла
  PieceMeshBuilder.cs  — построение мешей фрагментов
  EarClipper.cs        — алгоритм клиппинга (вырезы формы)
  PieceController.cs   — логика отдельного фрагмента
  Board.cs             — игровой стол/поле
  DragController.cs    — перетаскивание мышью
  HintSystem.cs        — подсказки
  ImageGenerator.cs    — генерация картинки пазла
  EnvironmentBuilder.cs— процедурная сцена
  UIManager.cs         — интерфейс
  AudioManager.cs      — звук
```
